# 🚀 PROJECT: AzureCertify AI Pro

Build a production-ready, scalable, secure web platform for Azure certification exams (AZ-900 → AZ-305), inspired by Pearson VUE and Credly, with:

- Azure-themed UI
- Keycloak authentication
- AI-powered exam generation & validation using Gemini
- Full DevOps + cloud-native architecture

---

# 🎯 CORE REQUIREMENTS

## 1. 🧭 EXAM PORTAL (PRIMARY ENTRY POINT)

Users must be able to:
- Select certification:
  - AZ-900 (Fundamentals)
  - AZ-104 (Administrator)
  - AZ-305 (Architect)

- Configure exam:
  - Mode: Practice / Exam
  - Difficulty: Easy / Medium / Hard / Mixed
  - Question count (10–60)
  - Time limit (dynamic)

---

## 2. 🤖 AI-DRIVEN EXAM SYSTEM (GEMINI)

Use Google Gemini for:

### A. Question Generation
- Generate Azure-specific exam questions dynamically
- Must include:
  - Scenario-based questions
  - 4–5 answer options
  - Correct answer
  - Detailed explanation

### B. Validation Pipeline (MANDATORY)
- Re-validate generated questions via second AI call
- Score:
  - Accuracy
  - Clarity
  - Exam relevance
- Reject low-quality questions automatically

### C. Post-Exam AI Analysis
- Identify weak areas
- Suggest study plan
- Recommend next exam

---

## 3. 🔐 AUTHENTICATION & SECURITY

Use Keycloak:

- OpenID Connect (OIDC)
- JWT validation in backend
- RBAC:
  - Student
  - Admin
  - Instructor
  - Proctor

### Security Requirements:
- Secure API gateway
- Token validation middleware
- Rate limiting
- Anti-cheating mechanisms:
  - Tab switch detection
  - Session integrity checks

---

## 4. 🎨 AZURE-THEMED UI/UX

### Exam UI:
- Left: Question navigator

# 🔄 SYSTEM FLOW

## Exam Flow:
1. User logs in via Keycloak
2. Selects exam
3. System fetches:
   - Stored + AI-generated questions
4. User takes exam
5. Auto-submit + scoring
6. AI analyzes results

---

## AI Flow:
1. Generate → Validate → Store → Serve
2. Analyze performance → Recommend improvements
